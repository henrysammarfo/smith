# Fact-check

1. Read `memory/FACT_CHECK.md` first.
2. Call Tavily search and/or TinyFish fetch/search (live keys in `.env`).
3. Mark VERIFIED / CORRECTED / UNVERIFIED with source URLs.
4. Update `memory/FACT_CHECK.md` and append `memory/SESSION_LOG.md`.
5. Never invent contest rules.
